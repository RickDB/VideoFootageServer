Export settings and check method

Relative paths use the configured export directory. Absolute paths must be mounted and writable on the server. Every check creates its own dated report folder, with screenshots grouped by site.

Camera screenshots use fresh frames. Dark / Hikvision-style placeholder frames are skipped using an image heuristic, which can also skip real low-light scenes. Every skipped frame is flagged for review.

A 28-day check confirms a recording spanning the target date/time on each enabled camera. It does not prove continuous coverage or decode the recording. Recorder and site timezone configurations must agree.
